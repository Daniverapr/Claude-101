| `assets/` | Fotos, logos, íconos y fuentes (Ashcroft) |

## Editar el sitio

1. Edita cualquier archivo `.html` o los estilos.
2. Sube los cambios a GitHub:
   ```bash
   git add .
   git commit -m "Describe tu cambio"
   git push
   ```
3. Netlify republica automáticamente en ~30 segundos.
